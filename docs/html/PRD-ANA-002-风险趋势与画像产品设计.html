风险趋势与画像（F23）

功能编号 F23 · 风险预警闭环域 · 第一波 · 关联文档 MOD-ANA-002（模块技术设计）

1. 背景与目标

平台已经能实时发现风险事件（F18 规则引擎）、分级通知（F19）、派单处置（F20/F21）并给司机打出每日安全评分（F22）。但坐席和安全管理员还缺一个回看与对比的工具：一段时间里风险是变多还是变少？哪辆车、哪个司机、哪个企业问题最集中？哪些路段事故高发？

F23 就是把这些历史数据"摊开来看"的分析页面。它只读——不新增任何业务数据，只在已有的风险事件、工单、干预、评分之上做统计与可视化，帮助管理者发现问题规律、评估处置效果、定位高风险对象。

一句话定位：F18~F22 负责"发现—处置—打分"，F23 负责"复盘—对比—找规律"。

2. 四个分析视角

页面顶部统一选择时间范围（近 7 日 / 近 30 日 / 近 90 日 / 自定义，最长一年），下方四个标签页对应四个视角：

趋势分析
风险随时间怎么变
·
对象画像
某车/司机/企业的体检报告
·
黑点路段
哪些位置事故高发
·
对比排行
谁的风险最高

四个视角都支持全网 / 企业 / 司机 / 车辆四种维度切换，数据范围随登录人的可见部门自动收敛。

3. 趋势分析

用折线图展示所选范围内风险事件数量随时间的变化，可按日 / 周 / 月粒度聚合：

  • 总量线 + 分级线：一条事件总数曲线，叠加高/中/低三个风险等级的分量曲线，直观看出"量涨了还是结构恶化了"。
  • Top5 事件类型：自动挑出期间最多的 5 类事件（超速、疲劳、分心等）做堆叠柱，回答"主要风险来自哪里"。
  • 没有数据的时段补 0，曲线连续不跳变。

口径：事件时间取事件发生时间，缺失时退回入库时间；与预警处理规则一致，只统计平台留痕的事件，不含全量视频。

4. 对象画像

选定一辆车、一个司机或一个企业，生成该对象的"风险体检卡"，四块内容：

分区内容业务含义
概览头卡周期事件总数、高危数、最新评分与等级一眼看出对象整体风险水位
评分曲线引用 F22 每日安全评分随时间变化处置后行为是否改善
事件构成各类型事件占比（雷达/占比条）问题集中在哪类行为
干预与闭环事件→工单→干预→闭环漏斗 + 工单 Top5处置是否跟得上、闭环率如何

司机归属为近似口径：事件按车牌归集，车辆换司机后历史事件跟随当前司机，页面已标注。

5. 黑点路段

把期间所有风险事件的位置按网格聚类（可选 100/200/500 米方格），找出事件最密集、等级最重的 Top N 个"黑点"，左侧列表 + 右侧地图标记联动，颜色按加权风险分分档（红/橙/黄）。

本期是网格近似，不是真实路段：平台尚未接入路网数据，黑点按地理方格聚合，用于定位"高发区域"。待路网匹配上线后升级为按实际路段聚合，接口结构不变。

6. 对比排行

在周期内对司机或车辆按等级加权风险分（高3/中2/低1 累加）排名，输出 Top N 榜，附带事件数、高危数与最新评分。点某一行可直接跳到该对象的画像页深入查看。

7. 数据范围与权限

  • 功能权限 analysis:profile:view：超级管理员、安全管理员可见"分析决策 → 风险趋势与画像"；调度监控员、企业车队长不可见（菜单不显示 + 直访拦截 + 接口 40301 三层一致）。
  • 数据范围沿用平台统一口径：受限用户只能看到自己可见部门子树内车辆的事件/工单/评分，黑点、趋势、排行同步收敛。
  • 全页面只读，不产生任何写操作。
